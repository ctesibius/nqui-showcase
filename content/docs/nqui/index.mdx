Plain-language guide for **app builders**, **designers**, and **inexperienced UI engineers** learning how `@nqlib/nqui` thinks about actions, forms, surfaces, and overlays.

Install with `pnpm add @nqlib/nqui`. API notes: [Installation](/docs/nqui/installation).

## How to read

1. **Intention** — what the product is trying to do.
2. **How** — what you import / compose in the UI.
3. **When not to** — anti-patterns and wrong control for the job.

Prefer concrete screens over abstract prop tables. Practice on the live [**/catalog**](/catalog) and [**/nqui**](/nqui) recipes — safe places to try variants.
