title: Concepts
description: How @nqlib/nqui splits core components, optional peers, and the live catalog.
---

nqui is the **component kit** for nqlib surfaces: tokens + primitives in `@nqlib/nqui`, optional peers for heavier features, and a **live catalog** on this site (not inside the npm package).

| Layer | Where |
|-------|-------|
| Core components + tokens | `@nqlib/nqui` + `@nqlib/nqui/styles` |
| Optional peers / subpaths | Command, DataTable, Calendar, Sonner, Drawer, Sortable, … |
| Live variants & recipes | [/catalog](/catalog) · [/nqui](/nqui) |
| Host | Your ThemeProvider, routes, data, brand token values |

For charts, see [nqchart](/docs/nqchart). For grids and Gantt, see [nqgrid](/docs/nqgrid) and [nqgantt](/docs/nqgantt).
