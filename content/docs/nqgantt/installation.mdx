---
title: Installation
description: Add @nqlib/nqgantt to a React app.
---

```bash
pnpm add @nqlib/nqgantt @nqlib/nqgantt-engine
```

Peer React 18 or 19. Import the UI from `@nqlib/nqgantt/ui` and types/helpers from `@nqlib/nqgantt`:

```ts
import { GanttRoot } from "@nqlib/nqgantt/ui";
import type { GanttFeature, GanttDependency } from "@nqlib/nqgantt";
```

Track versions on npm: [`@nqlib/nqgantt`](https://www.npmjs.com/package/@nqlib/nqgantt).
