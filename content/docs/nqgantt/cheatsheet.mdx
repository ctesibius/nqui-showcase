## Create / edit links

| Action | How |
|--------|-----|
| Create | Hover bar → drag **port** to another port |
| Select | Click the **edge** |
| Type | Toolbar **FS SS FF SF** |
| Lag | Toolbar **− / +** (`+Nd` chip on edge) |
| Delete | Red **×** or Delete/Backspace |

→ [Dependencies](/docs/nqgantt/dependencies) · [Dependency types](/docs/nqgantt/dependency-types)

## Auto-schedule

| Toggle | Effect |
|--------|--------|
| **On** (strict) | Move A → B follows (push and pull ASAP) |
| **Off** (flexible) | Move A → B stays; link still stored |

→ [Auto-schedule](/docs/nqgantt/auto-schedule) · [Critical path](/docs/nqgantt/critical-path)

## Types (pick per link)

| Type | Remember |
|------|----------|
| **FS** | Then start B (default sequence) |
| **SS** | Start together |
| **FF** | Finish together |
| **SF** | Rare handoff |
