**Intention:** In one short session, install `@nqlib/nqchart`, compose one bar, and click a mark so you see `seriesKey` and `category` land in your handler.

## Prerequisites

- A React 18/19 app with Tailwind (or your own layout).
- Install the published package and peers — details: [Installation](/docs/nqchart/installation).

```bash
pnpm add @nqlib/nqchart echarts motion
```

Current line: **0.3.0**.

Optional: try the same flow on the live lab at [**/charts/lab**](/charts/lab). The gallery at [**/charts**](/charts) only proves drawing.

## First path (15 minutes)

### 1. Compose one bar

```tsx
import {
  NQBarChart,
  Bar,
  XAxis,
  Grid,
  Tooltip,
} from "@nqlib/nqchart/bar-chart";
import type { ChartConfig } from "@nqlib/nqchart";

const config = {
  plan: { label: "Plan", color: "var(--chart-1)" },
} satisfies ChartConfig;

export function SpendBar({ data, onMarkClick }) {
  return (
    <NQBarChart config={config} data={data} onMarkClick={onMarkClick}>
      <XAxis dataKey="month" />
      <Grid />
      <Bar dataKey="plan" />
      <Tooltip />
    </NQBarChart>
  );
}
```

`config` keys **are** series ids (`dataKey`). Display labels live on `config.plan.label`, not as the event key. See [Cheatsheet](/docs/nqchart/cheatsheet).

### 2. Click a mark

1. Click a bar. Your handler should receive `seriesKey` (= `dataKey`, e.g. `plan`) and the category (month), not the legend label.
2. Click empty plot — nothing fires. Click a `null` datum — nothing fires.

If `seriesKey` is a pretty label, the host filter will miss.

### 3. Wire the host

Keep selection in **your** state. The chart only reports:

```tsx
onMarkClick={(e) => setFilter({ month: e.category, series: e.seriesKey })}
```

Do not ask the chart to own a cross-filter set. See [Design philosophy](/docs/nqchart/philosophy) and [Interaction](/docs/nqchart/interaction).
