---
title: Concepts
description: How @nqlib/nqgrid is meant to be used.
---

nqgrid is a **headless** engine. You mount it in your own product chrome rather than consuming a catalog of styled cells.

Typical surfaces:

- Spreadsheet / pivot
- Project board
- Column models, field panels, schema editors

For chrome around the grid, use [nqui](/docs/nqui). For timelines over the same work items, see [nqgantt](/docs/nqgantt).
