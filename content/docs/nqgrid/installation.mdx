---

description: Add @nqlib/nqgrid to a React app.
---

```bash
pnpm add @nqlib/nqgrid
```

Peer React 18 or 19. Import from the published package (`@nqlib/nqgrid` and `@nqlib/nqgrid/engine`).

Track versions on npm: [`@nqlib/nqgrid`](https://www.npmjs.com/package/@nqlib/nqgrid).
