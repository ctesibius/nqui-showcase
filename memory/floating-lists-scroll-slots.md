# Floating list ScrollArea + multi-line slots

**Hook:** Select / Combobox / Command long lists or title+description rows  
**Type:** convention  
**Fixed note:** `.agents/skills/fixed/fixes/floating-lists-scroll-highlight-multiline.md`

Use nqui **0.7.4+** item content slots (`*ItemContent` / `*ItemTitle` / `*ItemDescription`). Do not wrap `CommandList` / `SelectContent` in another ScrollArea. Title alone is the closed-field label for Select/Combobox.
