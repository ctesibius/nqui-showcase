# Impeccable — nqui-showcase

## Design Context

### Users
Developers and design engineers evaluating the nqlib stack (nqui, nqgrid, nqchart, nqgantt)
by browsing live, copyable patterns. Secondary: the maintainer exporting block surfaces
(screenshots) into slide decks and docs. Viewing context: desktop, both themes, often
side-by-side with an editor.

### Brand Personality
Calm, engineered, exact. "Blocks, not screenshots" — everything on the page is real and
running. The chrome defers; the content (data, components) carries the interest. Closest
in-repo articulation: the landing's "factory" framing and the Sales ledger's
"timeless ink report — hairline rules, no rainbow."

### Aesthetic Direction
- Editorial/print instrument: hairline rules, uppercase mono kickers, tabular numerals,
  figure-style framing. Think annual-report figure, not SaaS dashboard card.
- Color discipline: neutral ink surfaces; chart hues (`--chart-N`) are the only saturation,
  and they appear once — in the visualization — with at most tiny keyed swatches elsewhere.
- Both themes via nqui tokens only. No hardcoded palettes, no new fonts inside blocks
  (blocks inherit the app's type stack; mono-vs-sans contrast is the lever).
- Anti-references: icon-in-circle chips above headings, per-item tinted cards, colored
  side-stripe borders, glassmorphism as decoration, identical card grids.

### Design Principles
1. The data is the decoration — remove any ornament that isn't carrying information.
2. Annotate structure, not surfaces: transitions, seams, and boundaries are first-class.
3. One colorful object per surface; everything else is ink.
4. A block must survive a screenshot: self-explanatory header, source line, no dead chrome.
5. Rules (hairlines) organize; cards are reserved for genuinely separate surfaces.
